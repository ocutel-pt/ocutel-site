# Ilustrações ornamentais do processo

Criadas com o ImageGen integrado em 13 de outubro de 2026. Referência visual: o galo oficial, usado apenas para orientar o detalhe ornamental e a paleta. Estas ilustrações editoriais são separadas da identidade oficial; não são novos logótipos. Os ficheiros em `brand/` permanecem intactos.

Os PNG originais conservam a transparência gerada. As versões `-320.png` são apenas reduções para apresentação no site, sem recorte nem alteração de conteúdo.
